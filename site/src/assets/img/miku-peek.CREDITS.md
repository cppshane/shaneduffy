# Miku sprite

Character sprites: BYP Studio and Chaim Videogames, Miku 'n Pop.
Hatsune Miku character: Crypton Future Media.

Selected source: https://www.spriters-resource.com/pc_computer/mikunpop/asset/46493/
Sheet uploaded by: Ploaj.

The local miku-idle.png contains the idle frames from the selected Miku 'n Pop artwork.
PNG mirror: https://github.com/CharlesWiiFlowers/MikuPet/blob/main/assets/characters/miku/idle.png
The mirror credits BYP Studio and Chaim Videogames and the same Spriters Resource sheet.
The PNG was downloaded unchanged. No application code or JSON metadata was copied.

CSS displays twenty 64x100 frames as a two-second idle loop, with the lower
portion clipped by the page edge. Animation pauses when hidden and respects
prefers-reduced-motion.
